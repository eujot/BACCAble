## Scope and interpretation

This checkout and these sessions only; not a universal Alfa Romeo or cross-model DBC.

Zero-based byte indexes; bit 0 is LSB. Parts are concatenated in listed most-significant-first order; physical = raw * scale + offset.

`implementation` means a field is decoded or consumed in the source snapshot.
`comment` means only a historical source interpretation.
`capture` is reserved for a reviewed empirical layout with its own evidence.
Origin alone does not prove physical validation. ON/OFF temporal agreement
is supporting evidence; counters,
concurrent actions and conflicting labels can produce false matches.

Parts below are concatenated from left to right, most significant part first.
Physical values use the listed scale and offset; these printed numbers are rounded.
The JSON retains the conversion precision and explicit guards.

- RX capture only; own firmware TX is not recorded.
- No IDE/RTR flag in binary records; do not infer these flags from a shared numeric ID.
- Host timestamps are receipt times and batch across USB; board clocks have no common epoch.
- Startup loss counts can saturate at 65535.
- Frame presence or firmware implementation is not independent physical validation.

## Recorded markers and empirical baselines

The JSON `marker_index` links catalog markers and original custom events to
candidate fields and session/event IDs. `no_event_decoder` is an explicit gap,
not evidence that a vehicle function is absent. Derived events stay separate.

`frame_templates` combine stable bits across complete recordings; the remaining
bits are variable or unproven. They help spot new behavior on an old identifier.
A single-session template is weaker than repeated observation. Diagnostic IDs
and identity-bearing body-command payloads are excluded from stable-value templates.
Templates never supply a physical meaning for an unknown frame.

```sh
baccable dictionary --role BH --id 0x46C
baccable dictionary --role BH --id 0x46C --data '00 00 00 00 00 00 04 00'
baccable session decode SESSION --role BH --id 0x46C --limit 20
```
